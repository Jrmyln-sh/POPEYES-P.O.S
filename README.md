# Popeys Point of Sale
The Popeyes Ordering System is a console-based ordering and payment system written in C language.
It simulates a real-life fast-food ordering experience, allowing users to place orders via Counter or Kiosk, choose food items, manage a cart, apply discounts, and complete payments using Cash or GCash.
This project demonstrates procedural programming, menu-driven systems, input validation, and basic transaction processing in C.
